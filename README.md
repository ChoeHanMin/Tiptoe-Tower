# Tiptoe Tower

> 100층에서 1층까지, 통통 튀어 내려가자. 단, 아랫집은 깨우지 말고.

**플레이:** https://choehanmin.github.io/Tiptoe-Tower/

층간소음 코믹 아케이드 · 1인 · 한 판 30초~2분 · 한 손 조작

`index.html` 파일 하나로 동작합니다 (서버·로그인·외부 라이브러리·이미지 없음). 브라우저로 열면 바로 플레이할 수 있어요.

## 조작

- 공은 자동으로 통통 튀고, 플레이어는 **좌우로만** 움직입니다.
  - 모바일: 화면 왼쪽/오른쪽 절반 누르기
  - PC: ← → (또는 A / D), Enter로 시작

## 기본 규칙

- 바닥 **구멍**으로 떨어지면 한 층 아래로 내려갑니다.
- 위에서 **가시 천장**이 내려옵니다. 닿으면 게임 오버.
- **딱딱한 바닥**에서 튀면 "쿵!" → 아랫집 주민이 깨고 소음 게이지가 오릅니다.
- 소음 100% → 경비실 호출로 게임 오버. **이불** 위에서 튀면 조용해지고 소음이 내려갑니다.
- 민원이 쌓이면 **경비원**이 출동해 공을 쫓아옵니다. 바닥 근처에서 붙잡히면 게임 오버.

## 입주민 단체방 (실시간 민원)

화면 위쪽에 입주민 단체 채팅방이 떠서 실시간으로 민원이 올라옵니다.

- 깨운 집 호수로 메시지 표시 (예: `84F 02호: 아니 무슨 볼링 치세요?`)
- 민원 5건 → 관리사무소 "소음 발생 위치 확인 중", 9건 → "경비원 출동 예고", 13건 → **경비원 출동**
- 조용히 콤보를 이어가면 "요즘 윗집 조용하네요?" 같은 칭찬도 올라옴

## 주민 성격

| 주민 | 특징 |
|---|---|
| 일반 주민 | 쿵 한 번에 깸 |
| 예민한 주민 | 이불 위 착지에도 반응 (2번이면 깸), 깨면 소음 +8 |
| 잠귀 어두운 주민 | 3번 쿵 해야 깸 |
| 아기 있는 집 | 깨면 울음 → 소음 +15, 위·아래 집까지 깨움 |
| 잔소리 할아버지 | 깨면 빗자루로 천장을 쾅쾅 → 윗층 공이 튕겨 오름 |
| 밤샘 게이머 | 이미 깨어 있음. 소음에 관대 (소음 30%만 반영) |

## 층별 테마

| 구간 | 테마 | 주요 등장 요소 |
|---|---|---|
| 100~81층 | 일반 아파트 | 이불, 블록, 트램펄린, 로봇청소기 |
| 80~61층 | 반려동물 아파트 | 강아지, 고양이, 선풍기, 움직이는 이불 |
| 60~41층 | 어린이 아파트 | 장난감 블록·자동차, 트램펄린, 아기 |
| 40~21층 | 노후 아파트 | 삐걱 마루, 무너지는 바닥, 유리 바닥, 세탁기, 할아버지 |
| 20~11층 | 민원 집중 구역 | 예민한 주민 다수, 유리 바닥, 세탁기 |
| 10~2층 | 경비원 순찰 구역 | 진입 즉시 경비원 추격 + 모든 방해 요소 |
| 1층 | 탈출 | 아파트 전체를 보여주며 깨운 집 표시 |

## 방해 요소

| 요소 | 효과 |
|---|---|
| 마룻바닥 | 쿵 (소음 +12) |
| 이불 / 움직이는 이불 | 조용히 튐 (소음 −10) |
| 장난감 블록 | "아야!" 잠깐 못 움직임 |
| 트램펄린 | 높이 튐, 소음 +18, +5점 |
| 삐걱이는 마루 | "끼이익!" 소음 +16 |
| 유리 바닥 | 깨지며 소음 +25, 그대로 아래층 추락 |
| 무너지는 바닥 | 밟으면 잠시 후 사라짐 |
| 세탁기 | 진동 중에 밟으면 크게 튕겨 나감 |
| 선풍기 | 한쪽 방향으로 공을 밀어냄 |
| 로봇청소기 / 장난감 자동차 | 바닥을 돌아다니며 공을 밀어냄 (자동차는 빠름) |
| 고양이 | 공이 같은 층에 오면 쫓아와 밀어냄 |
| 잠든 강아지 | 근처에서 쿵 하면 "멍멍!" 소음 +15 |

## 아이템

| 아이템 | 효과 |
|---|---|
| 방음 매트 | 5초간 착지 소음 제거 |
| 깃털 | 5초간 천천히 떨어짐 (정밀 조작) |
| 얼음 시계 | 5초간 가시 천장 정지 |
| 수면 스프레이 | 깨운 이웃 3명을 다시 재움 |
| 유령 모드 | 3초간 바닥·장애물 통과 |
| 사과 편지 | 소음 −30% |
| 소음 폭죽 | 소음 +20, 콤보 끊김 — 대신 아래 5개 층 즉시 통과 |
| 황금 이불 (바닥) | 소음 −15, +30점 |

## 콤보 (무소음 연속 통과)

| 콤보 | 이름 | 배율 |
|---|---|---|
| 3 | 조용조용 | ×1.5 |
| 5 | 닌자 모드 | ×2 |
| 10 | 유령의 발걸음 | ×3 |
| 20 | 층간소음의 신 | ×5 |

쿵 하는 순간 콤보가 끊깁니다. 구멍 가장자리를 아슬아슬하게 통과하면 슬로모션 + 15점.

## 점수

| 행동 | 점수 |
|---|---|
| 한 층 내려가기 | +10 (× 콤보 배율) |
| 쿵 없이 한 층 통과 ("쉿!") | +20 추가 (× 콤보 배율) |
| 아슬아슬 통과 | +15 |
| 트램펄린 / 황금 이불 | +5 / +30 |

## 모드

| 모드 | 특징 |
|---|---|
| 일반 | 100층 → 1층 탈출 |
| 무한 | 지하(B1, B2…)로 끝없이 내려가기 |
| 심야 | 모든 소음 2배 |
| 대환장 | 규칙 반대! 소음 제한 없음, 이웃을 깨울 때마다 +50점 (민원 30건이면 경비원 출동) |
| 일일 도전 | 날짜별 시드로 모두에게 같은 아파트 구조 |
| 경비원 추격 | 천장 대신 경비원이 100층부터 쫓아옴. 소음이 클수록 빨라지고, 멀어지면 뛰어서 따라잡음. 얼음 시계로 경비원 정지 |
| 타임어택 | 최대한 빨리 1층 도착. 클리어 기록만 인정, 최고 기록(가장 빠른 시간) 저장 |

모드별 최고 점수가 따로 저장됩니다 (일일 도전은 날짜별, 타임어택은 최고 기록).

## 난이도

| 난이도 | 특징 |
|---|---|
| 하 | 공이 느리게 통통 튐 (높이는 같음), 구멍 넓음, 구멍 바로 옆에 이불이 자주 나옴, 천장·경비원 느림, 소음 덜 쌓임 |
| 중 | 조금 느린 바운스, 이불 넉넉 |
| 상 | 빠른 바운스, 기존 난이도 |

모드·난이도별로 최고 점수가 따로 저장됩니다.

## 도전장 대결 (기록 대결)

서버 없이 링크로 친구와 대결합니다.

1. 한 판이 끝나면 결과 화면에서 **도전장 보내기** → 이름 입력 → 링크 공유
2. 친구가 링크를 열면 **같은 아파트 구조·같은 모드·같은 난이도**로 시작
3. 플레이 중 오른쪽 위에 상대가 지금 몇 층에 있는지 실시간 표시 (추월하면 알림)
4. 끝나면 승패 표시 (타임어택은 완주 시간, 나머지는 점수로 비교), **반격 도전장**으로 되받아치기

## 실시간 대전 (멀티)

최대 4명이 같은 아파트를 동시에 내려갑니다.

1. 시작 화면 **실시간 대전** → 이름 입력 → **방 만들기** (방 코드 4자리 생성)
2. 친구는 방 코드 입력 후 **참가**, 또는 **초대 링크**로 바로 입장
3. 방장이 모드·난이도를 고르고 **시작** → 3초 카운트다운 후 동시 출발
4. 플레이 중 오른쪽 위에 현재 순위와 상대들의 층수가 실시간으로 표시
5. 콤보 단계를 올리면 상대에게 소음 민원 +8% 공격
6. 끝나면 순위표, **대기실로** 돌아가 다음 판

서버는 Firebase Realtime Database를 씁니다. 설정 방법은 [FIREBASE.md](FIREBASE.md) 참고. (현재는 서버 주소가 비어 있어 시작 화면에서 실시간 대전 버튼이 숨겨져 있음)

## 처음 하는 사람을 위한 안내

- **첫 5층 튜토리얼** (일반 모드 첫 판): 이동 → 마루 쿵 → 이불 → 구멍 통과 순서로 안내, 안내 중엔 천장이 멈춤. 설정에서 다시 볼 수 있음
- **소음 수치 표시**: 착지할 때마다 실제로 반영된 양을 표시 (예: "소음 +10", "소음 −10")
- **주민 특성 표시**: 자는 주민 위에 "귀 밝음 · 이불도 들림", "깊은 잠 ●○○" 같은 표시. 귀 밝은 집 위의 이불에는 귀 표시와 점선 테두리
- **경비원 출동 예고**: 단체방 머리에 "민원 7건 · 경비원까지 6건"
- **주민 반응 4단계**: 잠듦 → 뒤척임(흔들림) → 깜짝 놀람(!) → 항의

## 소음을 활용하는 선택: TV 소리가 큰 집

TV가 있는 방은 주기적으로 TV 소리가 커집니다 (조용 → 화면 깜빡임 예고 → "와아아!"). 시끄러운 순간에 착지하면 쿵 소리가 묻혀서 소음·주민 반응 없이 +10점, 콤보도 유지됩니다.

## 입주민 도감 · 이번 판 이야기

- 시작 화면 **입주민 도감**: 만난 주민 종류와 들은 대사를 수집
- 결과 화면과 결과 카드에 이번 판 요약 (예: "아기 2명과 강아지 3마리를 깨웠어요", "72F 게이머는 당신을 응원했어요")

## 설정

게임 중 오른쪽 위 일시정지 버튼(또는 Esc/P): 소리, 화면 흔들림, 단체방 메시지 개수(자동·3개·1개·접기), 튜토리얼 다시 보기. 화면을 벗어나면 자동으로 일시정지 (실시간 대전 중엔 멈추지 않음).

## 맵 규격

- 표준 맵(폭 360): 세로 화면(모바일), 일일 도전, 실시간 대전
- 넓은 맵(폭 960, 모바일 구간 3개): 가로 화면(PC)의 일반 플레이
- 도전장은 보낸 사람과 같은 규격으로 플레이 (넓은 맵 기록을 폰에서 열면 표준 맵으로 하고 안내 표시)

그림 에셋 요청 가이드는 [ASSET_PROMPTS.md](ASSET_PROMPTS.md) 참고.

## 연출

- 강한 착지: 화면 흔들림 + 충격파 링, 이불 착지: 이불이 푹 눌림
- 깬 집은 창문에 불이 켜지고, 게이머 집은 모니터 불빛
- 소음 90% 이상: 심장 박동 소리 + 붉은 테두리
- 경비원에게 잡히면 "잡았다!", 클리어 시 아파트 전체에 깨운 집이 불 켜지는 연출
- 결과 카드(1080×1920 PNG)에 실제로 깨운 집 위치가 표시된 아파트 그림

## 기술 메모

- 세로 화면(모바일)은 360×640, 가로 화면(PC)은 높이 540 기준으로 크게 확대 (1920×1080이면 960×540을 2배로 표시)
- PC의 넓은 층은 모바일 한 층 너비 구간을 이어 붙인 것: 구간마다 모바일과 같은 크기의 구멍·이불·장애물이 있어서 공과의 크기 비율·조작감이 모바일과 같음
- 층은 판마다 랜덤 생성 (일일 도전은 시드 고정), 화면에 보이는 층만 그림
- 물리 상수(`GRAV`, `BOUNCE`, `MOVE`, `FH`)와 구역 표(`ZONES`), 대사(`LINES`)는 파일 위쪽에서 쉽게 수정 가능
- 효과음은 모두 Web Audio로 합성 (`SFX` 객체)
- 최고 점수·해금 기록은 `localStorage` (막혀 있어도 게임은 동작)
