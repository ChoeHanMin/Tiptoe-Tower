# Tiptoe Tower

> 100층에서 1층까지, 통통 튀어 내려가자. 단, 아랫집은 깨우지 말고.

오토 바운스 무한 낙하 아케이드 (킬링타임) · 1인 · 한 판 30초~2분

## 플레이

`index.html` 파일 하나만 있으면 됩니다. 브라우저로 열기만 하면 플레이할 수 있어요 (서버·로그인·외부 라이브러리·이미지 없음).

- 공은 자동으로 통통 튀고, 플레이어는 **좌우로만** 움직입니다.
  - 모바일: 화면 왼쪽/오른쪽 절반 누르기
  - PC: ← → (또는 A / D), Enter로 시작
- 바닥 **구멍**으로 떨어지면 한 층 아래로 내려갑니다.
- 위에서 **가시 천장**이 내려옵니다. 닿으면 게임 오버.
- **딱딱한 바닥**에서 튀면 "쿵!" → 아랫집 불이 켜지고 이웃이 깨며 소음 게이지가 오릅니다. 100%가 되면 경비실 호출로 게임 오버.
- **폭신한 이불** 위에서 튀면 조용하고 소음 게이지가 내려갑니다.

## 층마다 나오는 물건

| 물건 | 등장 | 효과 |
|---|---|---|
| 마룻바닥 | 처음부터 | 기본 바닥. 튀면 쿵 (소음 +12) |
| 이불 | 처음부터 | 조용히 튐 (소음 −10) |
| 장난감 블록 | 96층부터 | 밟으면 "아야!" 하고 잠깐 못 움직임 |
| 엘리베이터 아이템 | 95층부터 | 먹으면 잠깐 동안 소리 없이 바닥을 뚫고 내려감 |
| 트램펄린 | 94층부터 | 높이 튀어 오름 (소음 +18), 대신 +5점 |
| 잠든 강아지 | 92층부터 | 근처에서 쿵 하면 "멍멍!" (소음 +15) |
| 로봇청소기 | 88층부터 | 바닥을 돌아다니며 공을 밀어냄 |

깊이 내려갈수록 천장 속도↑, 구멍 크기↓, 이불↓, 방해 물건↑.

## 점수

| 행동 | 점수 |
|---|---|
| 한 층 내려가기 | +10 |
| 쿵 없이 한 층 통과 ("쉿!") | +20 추가 |
| 트램펄린 밟기 | +5 |

최고 점수는 `localStorage`에 저장됩니다 (저장이 막혀 있어도 게임은 동작).

## 칭호

| 깨운 이웃 | 칭호 |
|---|---|
| 0명 | 전설의 조용한 이웃 |
| 1~3명 | 매너 이웃 |
| 4~8명 | 평범한 이웃 |
| 9~15명 | 소문난 쿵쿵이 |
| 16명 이상 | 아파트 전설의 쿵쿵이 |

## 기술 메모

- 캔버스 기준 해상도 360×640, 화면 크기에 맞춰 자동 확대·축소
- 층은 판마다 랜덤 생성, 화면에 보이는 층만 그림
- 물리는 "바닥에 닿으면 일정한 높이로 튀어 오름" 수준 — 상단 상수(`GRAV`, `BOUNCE`, `MOVE`, `FH`)로 쉽게 조절
- 효과음은 모두 Web Audio로 합성 (`SFX` 객체에서 교체 가능)
- 결과 카드: 1080×1920 PNG를 생성해 저장
